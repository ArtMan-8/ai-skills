# ai-skills

Agent Skills для технического текста и документации. Устанавливаются в Claude Code, Cursor, Codex, GitHub Copilot и другие агенты через [skills.sh](https://www.skills.sh/ArtMan-8/ai-skills).

## Установка

### С помощью AI-агента

Вставьте это в Claude Code, Cursor или другой агент:

> Покажи, какие skill доступны в `ArtMan-8/ai-skills`, затем установи `technical-language-core` командой `npx skills add ArtMan-8/ai-skills --skill technical-language-core` и подтверди через `npx skills list`.

### Из терминала

Установить весь набор skill (skill и агенты выбираются интерактивно):

```bash
npx skills add ArtMan-8/ai-skills
```

Установить все skill для конкретного агента:

```bash
npx skills add ArtMan-8/ai-skills -a claude-code  # например, cursor, codex, opencode, pi; без -a — выбор вручную
```

Установить один skill:

```bash
npx skills add ArtMan-8/ai-skills --skill technical-language-core -a claude-code
```

Добавьте `-g`, чтобы установить глобально. Без `-g` установка идёт в текущий проект: `.claude/skills/` для Claude Code и `.agents/skills/` для большинства остальных агентов.

## Skill

| Skill                                                                | Что делает                                                                                                                                                                                                                                   | Когда применять                                                                                                                                                                             |
| -------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| [`technical-language-core`](skills/technical-language-core/SKILL.md) | Создаёт, редактирует, проверяет и оценивает технический текст на языке документа. Для русского — полный каталог правил, для английского — базовый пакет контролируемого английского, для остальных языков — только языково-нейтральное ядро. | Используйте при написании, улучшении, проверке или оценке технического текста, а также при согласовании терминологии. Не задаёт структуру документов и не оценивает техническую истинность. |

# Исключения и запреты на механическую правку

- **Длина предложения.** Длинное предложение допустимо, если связи ясны. Числовой лимит — только по явному требованию; при явном требовании он обязателен.
- **Пассивный залог.** Допустим, когда исполнитель неизвестен, несущественен или тема текста — объект действия.
- **Порядок слов.** Русский язык допускает смысловое выделение и непрямой порядок; исправляй только реальную неясность.
- **Повторы.** Повтор точного термина или названия сущности может быть предпочтительнее местоимения.
- **Номинализации.** Иногда обозначают отдельное понятие («обработка запроса») и не подлежат замене глаголом.
- **Оговорки.** «Может», «обычно», «при необходимости», «не более» могут нести существенный смысл; не удаляй их как мусор.
- **Специальная лексика.** Не заменяй точные термины бытовыми аналогами.
- **Буквальные строки.** Цитаты, сообщения об ошибках, команды, ключи, API и идентификаторы сохраняй. Не редактируй фрагмент, который в самом тексте приведён как цитата внешнего источника или слова третьего лица. Кавычки в запросе, которыми выделен исходный текст для правки, — это разметка материала, а не цитата. Юридические и художественные формулировки не переписывай по правилам технического текста; назови ограничение и предложи альтернативу.
- **Неопределённость.** Не уточняй неизвестный субъект, механизм отказа или причину по догадке.
- **Обоснованная исходная формулировка.** Оставляй без изменений, если нет ясной пользы от правки.

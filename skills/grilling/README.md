# grilling

Agent Skill, который беспощадно расспрашивает о плане, решении или идее раундами по дереву решений, пока не останется нерешённых ветвей и молчаливых допущений. Отвечает на языке пользователя: русский запрос — русский раунд, английский — английский.

## Установка

```bash
npx skills add ArtMan-8/ai-skills --skill grilling
```

Подробнее — в [корневом README](../../README.md).

## Состав

- `SKILL.md` — правила интервью: фронтир и раунды, формат вопроса, пересчёт дерева, ответы, которые не закрывают вопрос, разделение фактов и решений, условие завершения.

Справочников и eval-набора у skill нет: вся инструкция помещается в `SKILL.md`.

## Как работает

**Дерево решений.** Каждое решение разветвляется на решения, которые от него зависят. Вопрос задаётся только тогда, когда его предпосылки уже улажены, — иначе пришлось бы угадывать ещё не прозвучавший ответ.

**Фронтир и раунды.** Фронтир — все вопросы, которые можно задать сейчас. Раунд — не больше пяти вопросов; если фронтир шире, в раунд идут пять самых дорогих, остальные переходят в следующий. Вопросы одного раунда не зависят друг от друга.

**Формат вопроса.** У каждого вопроса 2–4 варианта с плюсами и минусами (✅/❌) и рекомендация с обоснованием «Почему». Ответ «да» принимает рекомендацию целиком.

**Пересчёт дерева.** Ответы за раунд перестраивают дерево: улаженные решения раздвигают фронтир и разблокируют зависевшие от них вопросы. Следующий раунд задаётся уже по пересчитанному фронтиру.

**Факты и решения.** Факты skill ищет сам — файлы, код, инструменты, при необходимости через субагента. Решения выносит пользователю: каждое отдельно и с ожиданием ответа.

**Ответы, которые не закрывают вопрос.** «Не знаю» превращается в минимальную проверку или фиксируется как допущение с пометкой «не проверено». «Решай сам» принимает рекомендацию, но решение запоминается как принятое за пользователя. Противоречие с прошлым раундом не сглаживается, а становится отдельным вопросом.

## Когда закончить

Сессия завершена, когда фронтир пуст: каждая ветвь дерева пройдена, ничего не осталось молчаливо предположенным. Skill не действует, пока пользователь не подтвердит, что понимание общее.

## Когда не использовать

Для однозначных одношаговых задач, где нечего выяснять вопросами. Skill не заменяет исследование фактов и не принимает решения за пользователя без явной фиксации.
